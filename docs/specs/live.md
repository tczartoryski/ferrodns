# Live recursion implementation scope

Approved design: retain empty Cargo dependencies. Implement an isolated std-only HTTP/SSE binary and opt-in public-only resolver policy (ordinary CLI/simulator behavior unchanged). Events must be emitted synchronously during resolution, with query_start before socket exchange and query completion after it; never replay a finished trace. Bounded nonblocking channel disconnect/full sets cancellation. Per-request cancellation + 15s deadline must reach UDP/TCP waits; bound TCP reads against overall deadline (slow trickle cannot extend it).

Public-only policy: ASCII hostnames up to 253 chars, labels 1..63, forbid IP literals/numeric dotted names, single-label names, localhost/local/internal/home/lan/test/invalid/onion and reverse zones. Validate EVERY chased CNAME/glueless NS name. EVERY actual UDP/TCP endpoint validated at transport immediately before contact: fixed port53, no endpoint override, deny IPv4 non-global blocks incl 0/8,10/8,100.64/10,127/8,169.254/16,172.16/12,192.0.0/24,192.0.2/24,192.168/16,198.18/15,198.51.100/24,203.0.113/24,224/4,240/4; IPv6 restrict conservative global 2000::/3 minus documentation/transition/embedded/reserved blocks. Filter cached/referral/glueless addresses, with ultimate transport gate. Avoid private address final answers being used as upstream.

HTTP: loopback default unprivileged8080; explicit bind for container. ONLY GET /health and /resolve?name=...&type=A|AAAA, no DNS listener/proxy/custom upstream/root config. Reject unknown/duplicate params, oversized headers (>8KiB), body/chunk encoding, unsupported HTTP/method, invalid Origin. CORS only https://tczartoryski.github.io (path is not origin); local browser tests use same explicit Origin, never loosen published origin. Request read absolute3s, write timeout1s. Cap all connections16, active resolutions4, queries32, referrals12, cname8/depth4, event queue128 plus event count ceiling; global30 and per peer6 requests/min, bounded rate map. Do not trust arbitrary X-Forwarded-For; proxy environments rate per peer conservatively and global limit protects abuse. Acquire slots before spawning, RAII release cancellation on disconnect. No auto reconnect/repeat DNS after interruption. SSE named started/trace/done/error records, heartbeat; exact terminal status.

Frontend: site/viz/index.html retains upload/drop/sample/comparison. Add URL/domain input (browser URL parser only extracts hostname; no URL fetch, credentials reject), A/AAAA, resolve/cancel, status/timeout/errors; incremental waterfall/tree and pending query highlight. Controlled static site/viz/live-config.json endpoint null until remotely deployed AND verified. With endpoint null show honest unavailable state and disable resolution, never fake live animation. No arbitrary backend override query param. Local verification may modify served config in temporary directory ONLY. Bound/sanitize strings/events and use textContent, abort on unload/new input/file loading; races generation token. Explicit retry button/manual submission only.

Tests: existing cargo gates; simulated delayed emission before final result; public target matrix incl mapped IPv6 and overrides; malicious private glue + glueless answers + forbidden CNAME, private outbound socket never opened; deadlines/slow TCP; queue full/disconnect/cancel; HTTP parser/CORS/qtypes/rate/concurrency/slow clients; mock DOM URL input/lifecycle/injection plus real mobile browser and samples. No internet loadtesting, only paced example.com and one CNAME domain.

Deployment: portable multistage Dockerfile nonroot no port53, read-only runtime cap128MiB/pids64/cpus0.5, no capabilities; Render free blueprint plan free, no payment method. Outbound UDP/TCP53 must be proved on host, HTTPS SSE event arrival before terminal and dig comparison before enabling endpoint. Pages remains sample mode until proof. Docs record missing connected hosting account/token (only GitHub auth present, repository secrets empty); Render free cold start~1min,750h/month shared, suspension/no card limits; outbound53 unverified. Cloudflare Workers not native Rust UDP recursion; Fly no free tier; Oracle signup creditcard unapproved. Include minimal account authorization action and exact deployment/probe steps. Preserve DNSSEC/experimental caveats. CI static and security tests, no live network in CI.

Scope source/tests/scripts/site/docs/Dockerfile/.dockerignore/render.yaml/.github/workflows only. No git push/deploy or personal machine config by Codex. Never secrets, credentials, target/binary asset reads.
