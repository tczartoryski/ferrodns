Planned recordings

These are recording targets, not observed results.

  • Cold lookup: www.apple.com with an empty cache.
  • Warm lookup: the same name after its answer has been cached.
  • Timeout and failover: a timeout followed by another server, if captured.
  • Glueless delegation: resolving a nameserver address before continuing.
  • NXDOMAIN: an authoritative answer that a name does not exist.
  • TCP fallback: retrying a truncated DNS response over TCP.

Trace privacy

Published samples must contain only public-domain lookups. Remove local-network names, addresses, and other private information before publication.
