FerroDNS

A recursive DNS resolver from scratch in Rust — root to answer, standard library only.

A recursive resolver turns a domain name into a DNS answer. It follows referrals from root servers through the domain hierarchy, asks the authoritative servers, and caches answers for later lookups.
